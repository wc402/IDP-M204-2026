## FSM Branch
This branch contains the finite state machine (FSM) files. The folders organise old files from the previous code strucrure that were copied over from the code run from the line following test, but are no longer used.
FSM main is the executable file containing the robot class that allows the AGV to perform its necessary functions. The other files named after electrical components contain classes establishing the set up and operation of these components. Ensure that entities are named to allow them to be understood outside of the files in which they were defined.
